Logički tok aplikacije

Aplikacija je razvijena korištenjem MVC arhitekture. 
Prvo su kreirani modeli Pet i Appointment, koji predstavljaju životinje i njihove veterinarske preglede. 
Zatim su u klasi VetData definisani probni podaci i metode za njihovo pronalaženje.
Kontroler obrađuje zahtjeve korisnika i prosljeđuje podatke Thymeleaf HTML stranicama. 
Korisnik može pregledati listu životinja, listu pregleda i odabrati životinju kako bi vidio njene detalje i historiju pregleda. 
Podaci se čuvaju u memoriji, bez korištenja baze podataka.
